# Every Road Led Me to You ♥

*A personal journey through music, memories, and love.*

This small, noncommercial website was created as a gift for someone very special. It tells a story through sixteen songs, seven chapters, photographs, and reflections inspired by Texas roads, meaningful memories, personal growth, and hope.

Sometimes a song says what words cannot. This project is my way of bringing those songs and words together into one experience.

## The experience

- A nostalgic, mobile-friendly design
- Seven chapters and sixteen songs
- A YouTube playlist and personal photographs
- A separate letter with a playful password prompt

Built with HTML, CSS, and JavaScript and designed for GitHub Pages. All music belongs to its respective rights holders.

*Made with love, not perfection.* ♥
